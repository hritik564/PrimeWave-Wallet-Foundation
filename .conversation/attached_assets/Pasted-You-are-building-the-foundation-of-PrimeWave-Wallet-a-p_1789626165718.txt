You are building the foundation of **PrimeWave Wallet**, a production-oriented, strictly non-custodial, multi-chain EVM cryptocurrency wallet.

This is **PHASE 0A ONLY**.

Your job in this prompt is to establish a clean, maintainable project foundation. Do NOT build wallet functionality yet.

## PRODUCT CONTEXT

PrimeWave Wallet will eventually be released as a mobile application on:

* Google Play Store
* Apple App Store

It will be part of the PrimeWave ecosystem.

The final wallet will support:

* PrimeWave Chain as the PRIMARY network
* Ethereum
* BNB Smart Chain
* Polygon
* Arbitrum
* Base
* Optimism
* additional EVM-compatible networks
* native assets
* ERC-20 tokens
* verified tokens
* user-added tokens
* token discovery
* same-chain swaps
* PrimeWave ecosystem integrations
* Web3/DApp connectivity

The wallet will be STRICTLY NON-CUSTODIAL.

However, none of the above wallet functionality should be implemented in this phase.

# 4. SECURITY FOUNDATION

Create a security architecture document explaining the following immutable rule:

PrimeWave Wallet is strictly non-custodial.

The following must NEVER be transmitted to or stored on PrimeWave backend infrastructure:

* seed phrases
* mnemonic phrases
* private keys
* raw signing keys
* wallet passwords
* wallet PINs
* biometric secrets
* decrypted wallet vaults
* encryption keys

The future backend must never be responsible for signing user transactions.

Future transaction signing will occur locally on the user's device.

Do not implement these features yet.

Create documentation such as:

docs/SECURITY_ARCHITECTURE.md

Clearly mark this as a non-negotiable security invariant.
