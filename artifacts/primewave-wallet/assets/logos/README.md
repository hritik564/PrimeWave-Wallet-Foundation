# Wallet artwork

The local 128 × 128 PNGs were rasterized from the background variants in [Web3Icons revision 172f57f](https://github.com/0xa3k5/web3icons/tree/172f57f38fca75007002a4d707e08f33d82ba3a5/packages/core/src/svgs). Each filename maps to the upstream group and basename, e.g. networks-arbitrum-one.png comes from networks/background/arbitrum-one.svg. The included LICENSE reproduces the collection's MIT terms. Project names and marks identify their respective networks and currencies. The collection license does not grant endorsement or ownership of their trademarks.

| primewave | Neutral network glyph pending approved artwork | Neutral asset glyph |

The ERC-20 allowlist includes only Ethereum mainnet USDC, matched by chain ID and the contract published in [Circle's USDC address directory](https://developers.circle.com/stablecoins/usdc-contract-addresses). It supplies presentation metadata only. A symbol or an image never changes an asset's verification status. Unmapped contracts and missing identities use a generic asset glyph. The renderer accepts only bundled PNGs.
