WAVEX — PHASE 6.4: SWAP REVIEW & APPROVAL

We are now implementing Phase 6.4 of the WaveX wallet roadmap.

APPROVED PHASES:

- Phase 6.1 — Swap Architecture & Quote Model

This phase creates the secure Swap Review & Approval layer between the external quote and the future signing/execution phases.

IMPORTANT:

This phase MUST NOT sign a swap.

This phase MUST NOT send eth_sendRawTransaction.

==================================================
2. CORE SECURITY PRINCIPLE

A quote is NOT a transaction.

A provider transaction request is NOT trusted merely because it came from 0x.

A valid quote is NOT automatically authorized.

The user must explicitly review and approve the exact swap transaction context before it can ever reach Phase 6.5.

Document this invariant:

"WaveX never treats an external provider quote as signing authorization."

Before creating a review:

- quote is not expired
- quote lifecycle is quoted
- account matches
- sender matches

- sell asset matches
- buy asset matches
- sell amount matches
- slippage matches
